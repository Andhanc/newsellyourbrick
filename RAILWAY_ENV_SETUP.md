# 🔧 Настройка переменных окружения на Railway

## ✅ У вас уже есть переменные в Railway!

Судя по скриншоту, у вас уже установлены:
- ✅ `REACT_APP_CLERK_PUBLISHABLE_KEY`
- ✅ `REACT_APP_GOOGLE_CLIENT_ID`
- ✅ `VITE_EMAILJS_PUBLIC_KEY`
- ✅ `VITE_EMAILJS_SERVICE_ID`
- ✅ `VITE_EMAILJS_TEMPLATE_ID`

## Проблема
Переменные установлены, но не доступны во время сборки проекта, что приводит к ошибке "Missing Clerk Publishable Key".

## Решение

Railway автоматически делает переменные окружения доступными через `process.env` во время сборки. Код уже настроен для использования этих переменных.

### Что нужно проверить:

1. **Убедитесь, что переменная `REACT_APP_CLERK_PUBLISHABLE_KEY` имеет правильное значение:**
   - Нажмите на иконку глаза 👁️ рядом с переменной
   - Убедитесь, что значение начинается с `pk_test_` или `pk_live_`
   - Значение должно быть полным ключом от Clerk

2. **После изменения переменных Railway автоматически пересоберет проект:**
   - Проверьте логи сборки в Railway
   - Должны быть видны сообщения: `[VITE] 🔍 Проверка переменных окружения:`
   - Должно быть: `✅ установлен` для `REACT_APP_CLERK_PUBLISHABLE_KEY`

3. **Если переменная все еще не работает:**
   - Убедитесь, что значение не содержит лишних пробелов
   - Попробуйте удалить и заново добавить переменную
   - Проверьте, что используется правильное имя: `REACT_APP_CLERK_PUBLISHABLE_KEY` (не `VITE_CLERK_PUBLISHABLE_KEY`)

### Вариант 2: Использование .env файла (Альтернатива)

Если Railway не передает переменные как build arguments, создайте файл `.env.production` в корне проекта:

```env
REACT_APP_CLERK_PUBLISHABLE_KEY=pk_test_...
REACT_APP_GOOGLE_CLIENT_ID=ваш_google_client_id
REACT_APP_EMAILJS_SERVICE_ID=ваш_service_id
REACT_APP_EMAILJS_TEMPLATE_ID=ваш_template_id
REACT_APP_EMAILJS_PUBLIC_KEY=ваш_public_key
REACT_APP_API_BASE_URL=/api
```

⚠️ **ВНИМАНИЕ**: Не коммитьте `.env.production` в git, если он содержит секретные данные!

### Вариант 3: Runtime переменные (Если build args не работают)

Если переменные не доступны во время сборки, можно использовать runtime переменные:

1. Установите переменные в Railway Variables
2. Создайте API endpoint на сервере, который возвращает конфигурацию
3. Загружайте конфигурацию в клиенте при старте приложения

## Проверка

После настройки переменных:
1. Railway автоматически пересоберет проект
2. Проверьте логи сборки - должны быть видны переменные окружения
3. После деплоя приложение должно загружаться без ошибки "Missing Clerk Publishable Key"

## Где взять Clerk Publishable Key?

1. Зайдите на https://dashboard.clerk.com
2. Выберите ваш проект
3. Перейдите в Settings → API Keys
4. Скопируйте **Publishable Key** (начинается с `pk_test_` или `pk_live_`)

## Важные замечания

- Используйте `pk_test_` для тестирования
- Используйте `pk_live_` для продакшена
- Никогда не коммитьте секретные ключи в git
- Railway автоматически скрывает значения переменных в логах
