1. Документы по самому долгу

1. Кредитный договор (Loan Agreement).


2. Все дополнительные соглашения к кредитному договору.


3. График платежей по кредиту.


4. Подтверждение текущей задолженности (Debt Statement / Outstanding Balance).


5. История платежей заемщика.


6. Документы о дефолте (уведомления о просрочке, default notice).


7. Договор уступки долга (если долг уже перепродавался ранее).



2. Документы по обеспечению (недвижимости)

1. Нотариальный договор ипотеки.


2. Выписка из реестра недвижимости — Registro de la Propiedad.


3. Nota Simple (актуальная выписка по объекту).


4. Оценка недвижимости (Appraisal / Tasación).


5. Кадастровые данные — Catastro.


6. Фотографии объекта.


7. Адрес и описание объекта.


8. Наличие других обременений или ипотек.



3. Юридические документы

1. Документы по судебному процессу (если он уже начат).


2. Номер судебного дела.


3. Статус процедуры взыскания.


4. Решения суда (если есть).


5. Документы по исполнительному производству.



4. Документы по заемщику

1. Информация о заемщике (паспорт / регистрация компании).


2. Финансовое состояние заемщика.


3. Контактные данные.


4. Наличие других долгов или банкротства.



5. Документы по сделке покупки долга

1. Loan Sale Agreement / NPL Sale Agreement.


2. Договор уступки права требования (Assignment Agreement).


3. Подтверждение права фонда продавать долг.


4. Нотариальная передача прав требования.


5. Письмо-уведомление должнику о смене кредитора.



6. Дополнительно (часто запрашивают инвесторы)

1. Legal Due Diligence от юристов.


2. Valuation report.


3. Strategy memo (план взыскания).


4. Оценка сроков судебного взыскания.


5. Расчет потенциальной доходности.
