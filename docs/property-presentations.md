# Презентации объектов SellYourBrick

В карточке объекта откройте Property AI → «Презентация объекта». Сервер загружает актуальную запись из выбранной таблицы, готовит текст через OpenRouter и создаёт PDF из девяти слайдов в формате 16:9. Пользователь может открыть или скачать результат из существующего интерфейса Property AI.

В презентацию входят обложка, характеристики с практическими преимуществами, описание, удобства, две карты локации, галерея, формат продажи, порядок оплаты и следующий шаг. SellYourBrick присутствует на каждой странице. Удобства оформлены вертикальным списком с иконками Lucide справа от крупной фотографии. Тифани соответствует образцу: градиент `#31BEC8` → `#42C9D1`, основной акцент `#3AC4CD`. Заливки обложки, описания и условий сделки используют тот же тифани с белым текстом; цена на обложке и слайде продажи крупная и жирная. Этапы оплаты оформлены платиновыми карточками с тёмным текстом и тифани-иконками. Остальные слайды — светлый фон; типографика и композиции следуют референсу property listing.

## Конфигурация

- `OPENROUTER_API_KEY` — только серверная переменная. Не переносить в `VITE_*` или браузерный код.
- `PROPERTY_PRESENTATION_MODEL` — модель для презентаций. Если не задана, используется `PROPERTY_AI_MODEL`. Для текущего локального примера настроена `nvidia/nemotron-3.5-super-vl:free`, поскольку платная модель вернула ошибку баланса. Бесплатные провайдеры могут ограничивать частоту запросов.
- `FRONTEND_URL` / `PUBLIC_SITE_URL` — источник относительных фотографий `/uploads/...` при серверном рендеринге.
- При изменении серверных переменных перезапустите backend.

## Генерация из командной строки

```sh
npm run presentation:property -- --id 84 --table properties_houses --language ru
```

Разрешённые таблицы: `properties`, `properties_houses`, `properties_apartments`. Таблица важна: числовые ID в них могут совпадать. Поддерживаются `ru`, `en`, `de`, `es`, `fr`, `pl`, `sv`.

Для примера с неполным адресом можно явно задать район и выбрать обложку из исходной галереи:

```sh
npm run presentation:property -- --id 84 --table properties_houses --language ru --location 'Costa Adeje, Tenerife, Spain' --cover-photo 1
```

`--location` не меняет запись в базе. Геокодированная точка подписывается как приблизительная; окружность на карте не является границей участка. При отсутствии адреса/координат показывается отсутствие данных, случайная точка не подставляется. Поиск исключает одноимённые кафе, остановки и другие POI.

Результат сохраняется в `output/pdf/`. `--html-only` создаёт HTML без PDF. `--output` меняет выходную директорию. `--ids 83,84` запускает несколько объектов. Повторный рендер без платного запроса к модели:

```sh
npm run presentation:property -- --from-report tmp/property-presentation/SellYourBrick-properties_houses-84-ru.json
```

## Достоверность данных

- Характеристики и суммы берутся из записи объекта. Условия продажи и оплаты формируются кодом, а не моделью.
- Долги и доли имеют отдельные сценарии. Отключённый `buy_now_enabled` не превращается в доступную онлайн-покупку. Резерв 10% / остаток 90% рассчитывается только для включённой покупки целого объекта. Для аукциона указан входной депозит от 3 000 €, а итоговые условия резерва предлагается проверить при оформлении.
- Возможности и удобства из описания маркируются как слова продавца; импортированные булевы поля могут противоречить описанию и требуют проверки.
- Для известного импорта HouseTenerife фотографии берутся только из основной галереи исходного объявления. Логотипы, аватар и рекомендации соседних объявлений не используются. Внешний запрос разрешён только к указанному домену и пути объявления, без редиректов; произвольные URL из описания не открываются.
- Инфраструктура загружается из OpenStreetMap. При недоступном Overpass используется один небольшой видимый участок данных OSM с кешем на 48 часов. Карта использует реальные тайлы с атрибуцией и кешем на семь дней. Расстояния являются приблизительными по прямой от точки карты, без обещаний времени в пути. При непроверенной инфраструктуре это явно указано.
- Ошибка OpenRouter остаётся ошибкой генерации. Презентация не выдаёт шаблонный отчёт за успешный ответ AI.
- Кеш учитывает модель, версию шаблона, язык и содержимое записи объекта. Изменение цены или условий создаёт новый результат.

## Проверки и сохранённое поведение

Новые проверки находятся в `server/services/propertyPresentation.test.js`: сценарии продажи, расчёты, локали, обновление кеша, безопасный выбор медиа, точность локации, разбор инфраструктуры, обязательные страницы, брендирование, переходы генерации и parity web/legacy.

Галерея карточки объекта, access-gate документов/локации, карусель стратегий, сторис, профиль, переключение ролей, калькулятор инвестиций и сравнение не менялись. Новый режим работает внутри существующего Property AI. Web/legacy компонента и API-сервиса синхронизированы.

Ограничения регрессионных тестов: в исходном HEAD уже падали проверки AI-отчётов, ожидающие старые русские строки/предыдущие цвета PDF, а также отдельные проверки сторис и восстановления после ошибки объекта. Результаты исходного HEAD сравнивались отдельно, чтобы отличить эти ошибки от новой функциональности. Сборка и `git diff --check` должны проверяться после изменений.
