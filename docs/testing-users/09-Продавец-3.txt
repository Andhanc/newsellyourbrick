ПРОДАВЕЦ 3 — ОБЫЧНЫЙ ОБЪЕКТ И ДОЛИ

Задача: опубликовать любой обычный объект, создать отдельное предложение с долями и проверить продажи.

Данные: email __________; телефон/WhatsApp __________; язык __________; URL стенда __________; устройство/браузер __________.
Тестовая карта: 4242 4242 4242 4242; 12/34; CVC 123; Test User; индекс 28001. Не платить дважды.

Этап 1 — регистрация
[ ] Выбрать язык, зарегистрироваться, подтвердить email и заполнить профиль.
[ ] Нажать «Стать продавцом» и открыть кабинет продавца.
[ ] Посмотреть объекты, продажи, кошелёк, аналитику и подписки.

Этап 2 — тариф Pro
[ ] Открыть «Подписки» → Pro.
[ ] Отменить первую оплату, затем оплатить один раз.
[ ] Проверить активацию Pro и уведомления.

Этап 3 — обычный объект
[ ] «Объекты» → «Добавить объект» → «Продать сейчас».
[ ] Заполнить адрес, описание, характеристики, цену, фото и документы.
[ ] Сохранить черновик, оплатить публикацию и отправить на модерацию.
[ ] После одобрения найти объект в публичном каталоге.

Этап 4 — объект с долями
[ ] Создать отдельный объект с форматом «Доли/Совместные инвестиции».
[ ] Проверить ошибки для пустого, нулевого и недопустимого дробного количества.
[ ] Ввести корректное количество, цену и остальные данные.
[ ] Опубликовать объект и записать начальный остаток долей.
[ ] После покупок проверить покупателей, количество, суммы и уменьшившийся остаток.
[ ] Обновить страницу дважды: продажи и остаток не должны дублироваться.

Этап 5 — сверка
[ ] Проверить продажу обычного объекта.
[ ] Открыть аналитику и выгрузить Excel.
[ ] Сверить объекты, количество долей и суммы с кабинетом.

Итог
- Опубликованы обычный объект и объект с долями.
- Продажи отражены один раз, остаток долей корректен.
- Долговые объекты не создавались.
