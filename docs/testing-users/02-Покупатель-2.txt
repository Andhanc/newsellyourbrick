ПОКУПАТЕЛЬ 2 — ПОКУПКА ОБЪЕКТА И ДОЛИ

Задача: изучить платформу, купить любой доступный целый объект через «Купить сейчас» и долю любого доступного объекта.

Данные: email __________; телефон/WhatsApp __________; язык __________; URL стенда __________; устройство/браузер __________.
Тестовая карта: 4242 4242 4242 4242; 12/34; CVC 123; Test User; индекс 28001. Не платить дважды.

Этап 1 — регистрация и профиль
[ ] Выбрать язык, обновить страницу и проверить его сохранение.
[ ] «Профиль» → «Зарегистрироваться» → создать аккаунт на выданный email.
[ ] Подтвердить email из письма; при отсутствии проверить «Спам» и один раз запросить повторно.
[ ] Заполнить имя, страну и телефон/WhatsApp, сохранить и проверить после обновления.

Этап 2 — прогулка по платформе
[ ] С главной открыть «Купить сейчас», «Аукцион» и «Доли». «Долги» не открывать.
[ ] Посмотреть профиль, избранное, сравнение, депозит, историю, бронирования и подписки.
[ ] Открыть «Умную панель» и посмотреть, какие расчёты доступны.
[ ] В продавца не переключаться.

Этап 3 — тариф
[ ] Открыть «Подписки» и выбрать Pro.
[ ] Первую оплату отменить и убедиться, что тариф не активировался.
[ ] Повторить оплату один раз и проверить активацию Pro и уведомления.

Этап 4 — выбрать и купить целый объект
[ ] «Торги» → «Купить сейчас» → выбрать любой доступный объект, не занятый другим тестировщиком.
[ ] Проверить фото, цену, адрес, описание, характеристики, документы, локацию и продавца.
[ ] Добавить объект в избранное и рассчитать его в «Умной панели».
[ ] Нажать «Купить сейчас» → открыть PDF → проверить сумму → согласие → подпись.
[ ] Первую оплату резерва отменить и проверить отсутствие покупки.
[ ] Повторить путь, оплатить один раз и передать ID заявки координатору.
[ ] После завершения сделки проверить одну запись с правильной суммой в «Истории».

Этап 5 — купить долю
[ ] «Торги» → «Доли» → выбрать любой доступный объект с достаточным остатком долей.
[ ] Проверить цену одной доли, доступное количество, описание и ожидаемую итоговую сумму.
[ ] Выбрать назначенное количество и оплатить один раз.
[ ] Проверить портфель и уменьшившийся остаток долей.
[ ] Обновить страницу дважды: покупка не должна дублироваться.

Итог
- Куплен один любой целый объект.
- Куплена доля одного доступного объекта.
- Целая покупка и доля отражены по одному разу.
- Проверены уведомления сайта, email и WhatsApp.
