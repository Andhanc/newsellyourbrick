ПОКУПАТЕЛЬ 5 — PRO, ПОКУПКА ОБЪЕКТА И ДОЛИ

Задача: проверить тариф Pro, купить любой доступный целый объект и долю любого доступного объекта.

Данные: email __________; телефон/WhatsApp __________; язык __________; URL стенда __________; устройство/браузер __________.
Тестовая карта: 4242 4242 4242 4242; 12/34; CVC 123; Test User; индекс 28001. Не платить дважды.

Этап 1 — регистрация и знакомство
[ ] Выбрать язык, зарегистрироваться через «Профиль» и подтвердить email.
[ ] Заполнить профиль и телефон/WhatsApp; проверить сохранение после обновления.
[ ] Посмотреть «Купить сейчас», «Аукцион», «Доли», избранное, сравнение, депозит, историю и подписки.
[ ] «Долги» не открывать; в продавца не переключаться.

Этап 2 — тариф Pro
[ ] «Подписки» → Pro → начать оплату и отменить её.
[ ] Проверить, что Pro не активировался и списания нет.
[ ] Повторить оплату один раз и проверить тариф и уведомления.

Этап 3 — купить целый объект
[ ] «Торги» → «Купить сейчас» → выбрать любой свободный объект.
[ ] Проверить галерею, цену, адрес, описание, характеристики, документы, локацию и продавца.
[ ] Открыть «Умную панель», рассчитать выбранный объект и сверить данные с карточкой.
[ ] Вернуться в карточку → «Купить сейчас» → PDF → сумма → согласие → подпись.
[ ] Первую оплату резерва отменить; затем повторить путь и оплатить один раз.
[ ] Передать ID координатору и после завершения проверить покупку в «Истории».

Этап 4 — купить долю
[ ] «Торги» → «Доли» → выбрать любой объект с доступным остатком.
[ ] Проверить описание, цену доли, количество и итоговую сумму.
[ ] При необходимости пополнить депозит.
[ ] Отменить первую попытку покупки: доля не должна появиться.
[ ] Повторить и оплатить один раз.
[ ] Проверить портфель, уменьшившийся остаток и отсутствие дубля после двух обновлений.

Итог
- Pro активирован одной успешной оплатой.
- Куплен один любой целый объект.
- Куплена одна назначенная доля, портфель и остаток обновились.
