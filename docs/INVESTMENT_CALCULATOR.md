# Умная панель инвестора — как всё считается

Документ описывает формулы и логику расчётов на странице «Умная панель инвестора» (`src/pages/InvestmentCalculator.jsx`).

---

## 1. Входные параметры

| Параметр | Переменная | Единица | Описание |
|----------|------------|---------|----------|
| Цена объекта | `propertyPrice` | € | Стоимость покупки недвижимости |
| Стоимость ремонта | `renovationCost` | € | Дополнительные вложения в ремонт |
| Срок владения | `ownershipPeriod` | лет | Сколько лет считаем (1–30) |
| Рост рынка | `marketGrowthRate` | % в год | На сколько % в год растёт цена объекта |
| Годовой доход от аренды | `rentalIncome` | € | Арендный доход за **первый** год |
| Рост арендной платы | `rentalGrowthRate` | % в год | Рост аренды каждый год |
| Операционные расходы | `operatingExpenses` | % от дохода | Налоги, управление, ремонт — от годового дохода |
| Использовать ипотеку | `useMortgage` | да/нет | Включить расчёт кредита |
| Ипотечная ставка | `mortgageRate` | % годовых | Годовая ставка по кредиту |
| Срок кредита | `mortgageTerm` | лет | На сколько лет взят кредит |
| Первоначальный взнос | `downPayment` | % | Процент от цены объекта (10–100%) |

**Сценарии** только подставляют значения роста рынка и роста аренды:
- Оптимистичный: рост рынка 8%, рост аренды 5%
- Стабильный: 4% и 3%
- Пессимистичный: 2% и 1%
- Пользовательский: свои числа не трогаем

---

## 2. Общие вложения

```
Общие вложения = Цена объекта + Стоимость ремонта
```

В коде:
```js
totalInvestment = propertyPrice + renovationCost
```

Ремонт входит только в «общие вложения», на стоимость объекта по годам и на ипотеку не влияет.

---

## 3. Ипотека (если включена)

### 3.1. Первоначальный взнос (сумма в евро)

```
Первоначальный взнос (€) = Цена объекта × (Первоначальный взнос % / 100)
```

В коде:
```js
downPaymentAmount = (propertyPrice * downPayment) / 100
```

Если ипотека **выключена**, считаем, что платим всю цену сразу:
`downPaymentAmount = propertyPrice`.

### 3.2. Сумма кредита

```
Сумма кредита = Цена объекта − Первоначальный взнос (₽)
```

В коде:
```js
loanAmount = propertyPrice - downPaymentAmount
```

Без ипотеки: `loanAmount = 0`.

### 3.3. Ежемесячный платёж по ипотеке (аннуитет)

Используется формула аннуитетного платежа:

- `P` — сумма кредита (principal)
- `r` — месячная ставка = годовая ставка / 100 / 12
- `n` — число месяцев = срок кредита (лет) × 12

**Формула:**

```
Ежемесячный платёж = P × (r × (1+r)^n) / ((1+r)^n − 1)
```

Если месячная ставка `r = 0` (беспроцентный кредит):

```
Ежемесячный платёж = P / n
```

В коде:
```js
function calculateMonthlyPayment(principal, monthlyRate, numberOfPayments) {
  if (monthlyRate === 0) return principal / numberOfPayments;
  return principal * (monthlyRate * Math.pow(1 + monthlyRate, numberOfPayments)) / 
         (Math.pow(1 + monthlyRate, numberOfPayments) - 1);
}
// Вызов:
monthlyMortgagePayment = calculateMonthlyPayment(
  loanAmount,
  mortgageRate / 100 / 12,
  mortgageTerm * 12
);
```

### 3.4. Годовой платёж по ипотеке

```
Годовой платёж по ипотеке = Ежемесячный платёж × 12
```

Это значение **одинаково каждый год** (аннуитет не пересчитывается).

В коде:
```js
annualMortgagePayment = monthlyMortgagePayment * 12
```

## 4. Расчёт по каждому году

Для каждого года от 1 до «Срок владения» считаем:

- стоимость объекта на конец года;
- арендный доход за год;
- операционные расходы за год;
- расходы по ипотеке за год;
- итоговые расходы и денежный поток.

**Начальные значения перед циклом:**
- Текущая стоимость объекта = Цена объекта
- Текущий арендный доход = Годовой доход от аренды (за первый год)

### 4.1. Шаг по году (формулы)

Для года `year` (1, 2, 3, …):

**1) Стоимость объекта на конец года**

Сначала обновляем стоимость (рост с начала периода):

```
Стоимость объекта (конец года) = Стоимость объекта (начало года) × (1 + Рост рынка % / 100)
```

В коде перед использованием в расходах/доходах:
```js
currentPropertyValue *= (1 + marketGrowthRate / 100);
```

**2) Арендный доход за этот год**

Аналогично — сначала обновляем доход:

```
Арендный доход за год = Арендный доход (предыдущий год) × (1 + Рост аренды % / 100)
```

В коде:
```js
currentRentalIncome *= (1 + rentalGrowthRate / 100);
```

**3) Операционные расходы за год**

Считаются от арендного дохода **этого** года:

```
Операционные расходы за год = Арендный доход за год × (Операционные расходы % / 100)
```

В коде:
```js
yearOperatingExpenses = (currentRentalIncome * operatingExpenses) / 100;
```

**4) Платёж по ипотеке за год**

Один и тот же каждый год (если ипотека включена):

```
Платёж по ипотеке за год = Годовой платёж по ипотеке  (см. раздел 3.4)
```

В коде:
```js
yearMortgagePayment = annualMortgagePayment;
```

**5) Итоговые расходы за год**

```
Расходы за год = Операционные расходы за год + Платёж по ипотеке за год
```

В коде:
```js
yearExpenses = yearOperatingExpenses + yearMortgagePayment;
```

**6) Денежный поток за год**

```
Денежный поток за год = Арендный доход за год − Расходы за год
```

В коде:
```js
cashFlow = yearIncome - yearExpenses;
```

### 4.2. Что сохраняется по каждому году

В массив `yearlyData` для каждого года записывается:

| Поле | Значение |
|------|----------|
| `year` | Номер года (1, 2, 3, …) |
| `propertyValue` | Стоимость объекта на конец года |
| `rentalIncome` | Арендный доход за этот год |
| `operatingExpenses` | Операционные расходы за год |
| `mortgagePayment` | Платёж по ипотеке за год |
| `totalExpenses` | Операционные + ипотека |
| `cashFlow` | Доход − расходы за год |

## 5. Итоговые показатели (карточки на странице)

### 5.1. Общие вложения

Уже описано в разделе 2:

```
Общие вложения = Цена объекта + Стоимость ремонта
```

### 5.2. Стоимость через N лет

Берётся стоимость объекта на **последний** год расчёта:

```
Стоимость через N лет = propertyValue из последнего года в yearlyData
```

В коде:
```js
finalPropertyValue = lastYear?.propertyValue ?? propertyPrice
```

(Если лет 0, показывается исходная цена объекта.)

### 5.3. Доход от аренды за период

Сумма арендных доходов по **всем** годам:

```
Доход от аренды за период = сумма по всем годам (арендный доход за год)
```

В коде:
```js
totalRentalIncome = yearlyData.reduce((sum, d) => sum + d.rentalIncome, 0);
```

### 5.4. Чистый денежный поток

Сумма всех годовых денежных потоков за весь срок:

```
Чистый денежный поток = Сумма (Доход за год − Расходы за год) по всем годам
```

То же самое:

```
Чистый денежный поток = Доход от аренды за период − Сумма всех расходов за период
```

В коде:
```js
totalExpensesSum = yearlyData.reduce((sum, d) => sum + d.totalExpenses, 0);
netCashFlow = totalRentalIncome - totalExpensesSum;
```

## 6. Графики

### 6.1. «Доходы vs Расходы»

- **Ось X:** Год 1, Год 2, … Год N.
- **Линии:**
  - Доходы: для каждого года — `rentalIncome` из `yearlyData`.
  - Расходы: для каждого года — `totalExpenses` из `yearlyData`.

Под графиком:
- **Доходы:** сумма всех `rentalIncome` и **рост в %** (первый год → последний).
- **Расходы:** сумма всех `totalExpenses` и либо **рост в %**, либо **«X% от дохода»**.

**Почему рост доходов и расходов часто совпадает?**  
Расходы = операционные (% от дохода) + ипотека (фиксированная). Без ипотеки расходы — это постоянный процент от дохода, поэтому растут с той же скоростью, что и доход. В этом случае у расходов показывается доля от дохода («X% от дохода»), а не дублирующий процент.

### 6.2. «Рост стоимости»

- **Ось X:** Год 1, Год 2, … Год N.
- **Линия:** для каждого года — `propertyValue` из `yearlyData`.

## 7. Пример расчёта (числами)

**Входные данные:**
- Цена объекта: 10 000 000 €
- Ремонт: 500 000 €
- Срок владения: 5 лет
- Рост рынка: 4% в год
- Арендный доход (год 1): 600 000 €
- Рост аренды: 3% в год
- Операционные расходы: 15% от дохода
- Ипотека: да, ставка 10% годовых, срок 10 лет, первоначальный взнос 30%

**Шаг 1 — общие вложения**
- Общие вложения = 10 000 000 + 500 000 = **10 500 000 ₽**

**Шаг 2 — ипотека**
- Первоначальный взнос = 10 000 000 × 0,30 = 3 000 000 ₽
- Сумма кредита = 10 000 000 − 3 000 000 = 7 000 000 ₽
- Месячная ставка r = 10/100/12 ≈ 0,00833
- Месяцев n = 10×12 = 120
- Ежемесячный платёж ≈ 92 748 ₽
- Годовой платёж ≈ 1 112 976 ₽

**Шаг 3 — год 1**
- Стоимость объекта: 10 000 000 × 1,04 = 10 400 000 €
- Арендный доход: 600 000 × 1,03 = 618 000 € (если считать рост с первого года)
  - В коде в первый год сначала применяется рост: 600 000 × 1,03 = 618 000 — это доход за год 1.
- Операционные: 618 000 × 0,15 = 92 700 €
- Ипотека: 1 112 976 €
- Расходы: 92 700 + 1 112 976 = 1 205 676 €
- Денежный поток: 618 000 − 1 205 676 = −587 676 €

Дальше годы 2–5 считаются так же: стоимость и аренда растут по своим процентам, операционные — от дохода года, ипотека та же.

**Итоги за 5 лет:**
- Стоимость через 5 лет — значение `currentPropertyValue` после 5 итераций.
- Доход от аренды за период — сумма пяти значений аренды по годам.
- Чистый денежный поток — сумма пяти значений `cashFlow`.
