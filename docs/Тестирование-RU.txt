Тестирование SellYourBrick

Короткий сценарий для 10 человек: 6 покупателей и 4 продавца. Цель — провести 3 сделки на сайте.
Обязательные сделки: B1 покупает LOT-A у S1 «Купить сейчас»; B2 покупает долг LOT-B у S2 «Купить сейчас»; B5 покупает долю LOT-C у S3.
Дополнительно: B4 играет в аукцион LOT-D (ставки); B6 бронирует тест-драйв LOT-E; B3 открывает VIP и LOT-F.
Правила: только тестовая карта; оплату не жать дважды; LOT-A/B/C покупают только назначенные люди.
ВАЖНО: сейчас аукционы ещё не закончились, поэтому выиграть объект через аукцион нельзя. В аукционе можно только поиграть (ставки, депозит, KYC, уведомления). Реальную покупку делайте только через «Купить сейчас» или покупку доли.
1. Тестовая карта для всех платежей

Используйте эту карту Stripe Test для любой оплаты на сайте:
1. Номер карты: 4242 4242 4242 4242
2. Срок: любой будущий, например 12/34
3. CVC: любые 3 цифры, например 123
4. Имя на карте: любое, например Test User
5. Страна / почтовый индекс: любые, например Spain / 28001
Этой картой оплачивают: подписки, публикацию объекта, депозит, резерв «Купить сейчас», доли, тест-драйв.
2. Проверка уведомлений: почта и WhatsApp

После каждого важного действия проверяйте 3 места:
1. Уведомления в кабинете на сайте.
2. Письмо на email аккаунта.
3. Сообщение в WhatsApp, если номер привязан / включены WhatsApp-уведомления.
Что обязательно проверить:
1. Регистрация / подтверждение email.
2. Оплата подписки, депозита, резерва, доли, тест-драйва.
3. Новая ставка на аукционе / перебитая ставка.
4. Заявка на тест-драйв продавцу; подтверждение / отказ покупателю.
5. Завершение сделки «Купить сейчас» покупателю и продавцу.
Если письмо или WhatsApp не пришли — сделать скриншот кабинета и написать координатору. Не считать сделку проваленной только из-за этого, если на сайте статус верный.
3. Что делает координатор

1. Раздать роли, email, язык, тестовую карту и названия объектов.
2. Одобрять объявления продавцов в админке.
3. Подтверждать KYC покупателей.
4. После оплаты резерва по LOT-A и LOT-B завершить заявку в админке.
5. При необходимости открыть VIP-доступ / пометить LOT-F как закрытый лот.
6. Проверить, что тестовые WhatsApp-уведомления включены на стенде.
Важно: оплаченный резерв — ещё не финальная продажа. Финал ставит координатор.
4. Общий старт всех покупателей

1. Открыть сайт → выбрать свой язык → обновить страницу.
2. На главной посмотреть 4 стратегии: Аукцион, Купить сейчас, Долги, Доли.
3. Зарегистрироваться как покупатель и подтвердить email → проверить письмо.
4. Заполнить профиль и сохранить. Если есть поле телефона/WhatsApp — указать тестовый номер.
5. Открыть «Подписки» и перейти к своему тарифу ниже.
5. Покупатели — пошаговые пути

B1 — Starter: сравнил и купил LOT-A
1. Остаться на бесплатном Starter.
2. Зайти в «Торги» → «Купить сейчас».
3. Найти LOT-A и ещё 2 похожих объекта → добавить в избранное.
4. Открыть «Избранное» → «Сравнить» → выбрать LOT-A.
5. Нажать «Купить сейчас» → открыть PDF → согласие → подпись.
6. Проверить резерв 10% → один раз отменить оплату → убедиться, что не куплено.
7. Оплатить картой 4242… → в истории найти резерв → отдать номер координатору.
8. Проверить email и WhatsApp о резерве / покупке.
9. Дождаться финала от координатора → снова проверить сайт, email и WhatsApp → сверить с S1.
Готово: LOT-A куплен у S1 через «Купить сейчас»; уведомления проверены.
B2 — Pro: посчитал в умной панели и купил долг LOT-B
1. Купить Pro картой 4242…: сначала отменить оплату, потом оплатить → проверить активацию.
2. Проверить email/WhatsApp об активации подписки.
3. Зайти в «Торги» → «Долги» → найти LOT-B → посмотреть риск → в избранное.
4. Открыть «Умную панель» → посчитать обычный объект и LOT-B → выбрать LOT-B.
5. «Купить сейчас» → PDF → согласие → подпись → оплатить резерв картой 4242…
6. Проверить email/WhatsApp о резерве → отдать номер координатору → дождаться финала → сверить с S2.
7. Дополнительно: в умной панели на LOT-D проверить замок на стратегии «доля».
Готово: долг LOT-B куплен у S2 через «Купить сейчас»; уведомления проверены.
B3 — VIP: открыл закрытый клуб и LOT-F
1. Без VIP попробовать клуб, менеджера и LOT-F — должно быть закрыто.
2. Купить VIP картой 4242… или ввести промокод (сначала неверный, потом верный).
3. Проверить email/WhatsApp об активации VIP.
4. Открыть VIP-клуб → LOT-F → документы → локацию → персонального менеджера.
5. Выйти → проверить, что гостю LOT-F закрыт → войти снова.
6. По команде координатора можно купить LOT-F через «Купить сейчас» картой 4242… и проверить уведомления.
Готово: VIP открывает закрытый контент; уведомления проверены.
B4 — Starter: депозит, KYC и игра в аукцион LOT-D
1. Открыть LOT-D → ставка без депозита — должно блокировать.
2. Кошелёк → пополнить депозит до 3000 EUR или больше картой 4242…
3. Проверить email/WhatsApp о пополнении депозита.
4. Пройти KYC → дождаться подтверждения координатора.
5. Ставка ниже шага — ошибка; затем корректная ставка.
6. Попросить другого участника перебить ставку → проверить уведомление на сайте, email и WhatsApp.
7. Сделать ещё одну ставку.
Пометка: до конца таймера аукциона победить и купить лот через аукцион нельзя. Не ждите победы — покупку объекта делайте только через «Купить сейчас» в других сценариях. Здесь достаточно проверить ставки и уведомления.
Готово: минимум две конкурентные ставки; покупка через аукцион в этом тесте не требуется.
B5 — Pro: купил долю LOT-C
1. Купить Pro картой 4242…: отмена → повторная оплата → проверить активацию и email/WhatsApp.
2. «Торги» → «Доли» → открыть LOT-C → записать цену и остаток.
3. Посчитать в умной панели.
4. «Купить долю» → при необходимости пополнить депозит картой 4242… → выбрать количество.
5. Один раз отменить оплату — доли не должны появиться.
6. Оплатить картой 4242… → проверить портфель, уменьшение остатка, email/WhatsApp.
7. Обновить страницу дважды → не должно задвоиться → сверить с S3.
Готово: доля LOT-C куплена один раз; уведомления проверены.
B6 — Starter: AI и тест-драйв LOT-E
1. AI-чат: цель → страна/город → тип → бюджет → «покажи с тест-драйвом».
2. Открыть LOT-E. Если AI не нашёл — найти вручную.
3. Бронь без депозита → пополнить депозит > 0 картой 4242…
4. Выбрать даты → оплатить картой 4242… → статус «ожидает» → отдать номер S1.
5. Проверить email/WhatsApp о создании брони.
6. После подтверждения S1 проверить сайт, email и WhatsApp: даты, сумма, статус.
7. Создать вторую бронь → попросить S1 отклонить → проверить причину на сайте, email и WhatsApp.
Готово: тест-драйв пройден; уведомления confirm/reject проверены.
6. Общий старт всех продавцов

1. Нажать «Стать продавцом» → попасть в кабинет продавца.
2. Если есть кабинет покупателя — переключить роли туда-обратно.
3. Заполнить профиль и сохранить. Указать телефон для WhatsApp, если поле есть.
4. Открыть разделы: объекты, продажи, тест-драйв, кошелёк, подписки.
5. Выбрать свой тариф и перейти к своему сценарию.
7. Продавцы — пошаговые пути

S1 — Basic: выставил LOT-A и LOT-E
1. Остаться на Basic → «Добавить объект».
2. Заполнить LOT-A: адрес из подсказки, описание, 5+ фото.
3. Выбрать «Аукцион + Продать сейчас» → цены → документы.
4. Черновик → опубликовать картой 4242… (отмена → повтор) → модерация.
5. После одобрения проверить карточку на сайте → сообщить B1.
6. Создать LOT-E с тест-драйвом → оплатить публикацию картой 4242… → модерация → сообщить B6.
7. В «Тест-драйв»: подтвердить 1-ю заявку B6; отклонить 2-ю с причиной.
8. Проверить email/WhatsApp о заявках test-drive.
9. После оплаты B1 проверить резерв, email/WhatsApp → после финала координатора сверить продажу.
Готово: LOT-A продан B1 через «Купить сейчас»; заявки B6 обработаны.
S2 — Standard: выставил долг LOT-B
1. Купить Standard картой 4242…: отмена → оплата → проверить активацию и email/WhatsApp.
2. Добавить LOT-B как долг + «Продать сейчас».
3. Сначала без документов — ошибки; затем загрузить пакет по долгу.
4. Опубликовать картой 4242… → модерация → найти LOT-B в «Долгах».
5. Открыть аналитику / продвижение.
6. После покупки B2 проверить сайт, email и WhatsApp → сверить «Продажи» → «Долги».
Готово: LOT-B продан как долг через «Купить сейчас»; уведомления проверены.
S3 — Pro: выставил доли LOT-C
1. Купить Pro картой 4242…: отмена → оплата → проверить менеджера и email/WhatsApp.
2. Добавить LOT-C как «Доли»; проверить ошибки на пустое / 0 / дробное число.
3. Опубликовать картой 4242… → записать остаток долей.
4. После покупки B5: остаток уменьшился; продажа без дубля; проверить email/WhatsApp.
5. Аналитика + Excel → сверить с B5.
Готово: доли B5 отражены один раз; уведомления проверены.
S4 — VIP/Institutional: аукцион LOT-D и VIP-лот LOT-F
1. Активировать высший тариф: оплата картой 4242… или заявка менеджеру.
2. Проверить email/WhatsApp об активации тарифа / ответе менеджера.
3. Создать LOT-D как аукцион → оплатить публикацию картой 4242… → модерация.
4. Следить за ставками B4: сайт, email, WhatsApp. Победа покупателя в этом тесте не ожидается.
5. Создать LOT-F → после модерации попросить VIP-размещение.
6. Как гость LOT-F закрыт; B3 должен его увидеть.
7. Если B3 купит через «Купить сейчас» — сверить резерв/продажу и уведомления.
Готово: ставки на аукционе идут; VIP-лот открыт только VIP; покупка через аукцион не требуется.
8. Порядок сделок и успех

Порядок покупок: сначала доли B5↔S3, потом долг B2↔S2 через «Купить сейчас», потом обычный объект B1↔S1 через «Купить сейчас». Аукцион — только игра в ставки.
Если оплата зависла: не жать повторно, сделать скрин, отправить ID объекта/платежа координатору.
Тест успешен, если: опубликованы LOT-A…F; куплены обычный объект, долг и доля через «Купить сейчас»/доли; совпадают суммы у buyer и seller; на аукционе есть ставки (без обязательной победы); есть тест-драйв confirm+reject; VIP открывает закрытый лот; нет двойных списаний; по ключевым событиям пришли уведомления в кабинет, на email и в WhatsApp.
