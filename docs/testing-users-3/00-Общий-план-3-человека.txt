ОБЩИЙ ПЛАН ТЕСТИРОВАНИЯ — ГРУППА ИЗ 3 ЧЕЛОВЕК

1. Общее понятие

В тесте участвуют:
- Продавец 1 — готовит тестовые объекты, отправляет их на модерацию и обрабатывает действия покупателей.
- Покупатель 1 — знакомится с платформой, покупает целый объект и долю, делает ставки, бронирует тест-драйв и в самом конце проверяет переход в продавца.
- Покупатель 2 — знакомится с платформой, покупает другой целый объект, делает ставки и проверяет отклонение тест-драйва.

Участники не привязаны к заранее названным лотам. Покупатели выбирают любые два разных доступных объекта. Перед оплатой выбор обязательно согласовывается с координатором, чтобы два человека не купили один объект.

Долговые объекты в этом прогоне не создаём, не открываем и не покупаем.

2. Порядок работы группы

1. Координатор выдаёт каждому персональный файл, URL стенда, email, язык и тестовый номер телефона.
2. Все три участника регистрируются, подтверждают email и заполняют профиль.
3. Продавец создаёт тестовые объекты и отправляет их на модерацию.
4. Координатор одобряет объявления и сообщает покупателям, что каталог готов.
5. Покупатели выбирают два разных обычных объекта и сообщают выбор координатору.
6. Покупатели выполняют покупку и дополнительные сценарии.
7. Координатор подтверждает KYC, завершает заявки «Купить сейчас» и помогает со статусами.
8. Все участники проверяют итоговые данные и отправляют отчёт.

3. Тестовые данные участников

- URL тестового сайта.
- Персональный email, который ранее не использовался на стенде.
- Тестовый номер телефона/WhatsApp.
- Назначенный язык интерфейса.

Реальные паспортные данные и реальные банковские карты не использовать.

4. Тестовая карта

- Номер: 4242 4242 4242 4242
- Срок: 12/34
- CVC: 123
- Имя: Test User
- Страна/индекс: Spain / 28001

Карта используется для подписки, публикации, депозита, резерва «Купить сейчас», доли и тест-драйва.

5. Общие правила

1. Перед оплатой проверить назначение и сумму.
2. Не нажимать кнопку оплаты дважды.
3. Если платёж завис — сделать скриншот, записать время, URL и ID, затем обратиться к координатору.
4. После важного действия проверять:
   - уведомления в кабинете;
   - email;
   - WhatsApp, если он включён.
5. Если email не пришёл — проверить «Спам» и только один раз запросить повторную отправку.
6. Ошибку фиксировать как: шаг → ожидаемый результат → фактический результат → время → URL → скриншот.

6. Модерация и верификация

- Регистрация считается завершённой только после подтверждения email.
- Для ставок покупатель пополняет депозит, подаёт KYC и ждёт подтверждения координатора.
- Объявление продавца нельзя передавать покупателю, пока оно не прошло модерацию и не появилось в публичном каталоге.
- Оплаченный резерв «Купить сейчас» ещё не является финальной покупкой: итоговый статус выставляет координатор.

7. Что создаёт продавец

- Два разных обычных объекта с «Продать сейчас».
- Один отдельный объект с долями.
- Один активный аукцион.
- Один отдельный объект с тест-драйвом.

8. Что выполняют покупатели

Оба покупателя:
- проходят регистрацию и знакомятся с платформой;
- выбирают разные обычные объекты;
- покупают по одному целому объекту через «Купить сейчас»;
- делают конкурентные ставки в одном активном аукционе;
- создают по одной заявке на тест-драйв.

Дополнительно:
- Покупатель 1 покупает долю, получает подтверждение тест-драйва и последним шагом проверяет переход в продавца.
- Покупатель 2 получает отказ тест-драйва с понятной причиной и не переключается в продавца.

9. Критерии успеха

- Зарегистрированы и подтверждены три аккаунта.
- Все профили заполнены и сохраняются после обновления.
- Все пять тестовых сущностей продавца прошли модерацию.
- Два разных целых объекта куплены через «Купить сейчас».
- Одна доля появилась в портфеле, остаток уменьшился один раз.
- В аукционе есть конкурентные ставки после депозита и KYC.
- Одна бронь тест-драйва подтверждена, другая отклонена с причиной.
- Уведомления проверены по трём каналам.
- Нет двойных списаний и дублей.
