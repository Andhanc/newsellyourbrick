ПЕРСОНАЛЬНЫЙ ПЛАН — ПОКУПАТЕЛЬ 1

1. Ваша роль и общий смысл

Вы проверяете путь нового покупателя: регистрация, знакомство с платформой, покупка любого свободного целого объекта, покупка доли, ставки, подтверждённый тест-драйв. Только после завершения всего покупательского сценария вы проверяете переход в продавца.

Долговые объекты не открывайте. Реальные паспортные и платёжные данные не используйте.

3. Обязательная подготовка до персонального сценария

[ ] Открыть URL как гость.
[ ] Выбрать язык и обновить страницу: язык должен сохраниться.
[ ] Нажать «Профиль» → «Зарегистрироваться».
[ ] Создать новый аккаунт на выданный email.
[ ] Подтвердить email ссылкой или кодом из письма.
[ ] Если письма нет — проверить «Спам» и один раз запросить повторно.
[ ] Вернуться на сайт и убедиться, что аккаунт авторизован.
[ ] «Профиль» → редактирование → заполнить имя, страну и телефон/WhatsApp.
[ ] Сохранить, обновить страницу и проверить данные.
[ ] На главной открыть «Купить сейчас», «Аукцион» и «Доли», затем вернуться.
[ ] В меню открыть профиль, избранное, сравнение, депозит/кошелёк, историю, бронирования и подписки.
[ ] В каждом разделе проверить загрузку и понятность пустого состояния.
[ ] Проверить уведомление о регистрации в кабинете, email и WhatsApp.

В продавца сейчас не переключаться.

4. Выбрать объект для покупки

[ ] Открыть «Торги» → «Купить сейчас».
[ ] Выбрать любой доступный обычный объект.
[ ] До оплаты отправить координатору ссылку и получить подтверждение, что объект свободен.
[ ] Открыть карточку и проверить:
   - всю галерею и счётчик фотографий;
   - цену и валюту;
   - адрес и локацию;
   - описание и характеристики;
   - документы и условия доступа;
   - информацию о продавце.
[ ] Добавить выбранный объект и ещё два объекта в избранное.
[ ] Открыть «Избранное» → «Сравнение» и сравнить три объекта.
[ ] Вернуться к выбранному объекту.

5. Купить целый объект

[ ] Нажать «Купить сейчас».
[ ] Открыть PDF и проверить объект, сумму и условия.
[ ] Подтвердить согласие и подпись.
[ ] Проверить сумму резерва.
[ ] Начать первую оплату и отменить её.
[ ] Убедиться, что списания, резерва и покупки нет.
[ ] Повторить путь и оплатить резерв один раз.
[ ] Записать ID заявки, ID платежа и сумму.
[ ] Передать ID координатору и дождаться завершения сделки.
[ ] Открыть «История» и проверить одну запись с правильным объектом, суммой и финальным статусом.
[ ] Проверить уведомления сайта, email и WhatsApp.

6. Купить долю

[ ] Открыть «Торги» → «Доли».
[ ] Выбрать любой объект с доступным остатком долей.
[ ] Проверить описание, цену одной доли, остаток и итоговую сумму.
[ ] Сообщить координатору выбранный объект.
[ ] Купить назначенное количество долей один раз.
[ ] Открыть портфель и проверить покупку.
[ ] Обновить страницу дважды: запись и списание не должны дублироваться.
[ ] Сверить уменьшившийся остаток.

7. Поиграть в аукцион

[ ] Открыть «Торги» → «Аукцион».
[ ] Выбрать любой активный аукцион.
[ ] Проверить таймер, текущую цену и минимальный шаг.
[ ] Попробовать ставку без депозита: должна появиться блокировка.
[ ] Открыть «Депозит/Кошелёк» и пополнить депозит тестовой картой.
[ ] Подать KYC и передать ID координатору.
[ ] Дождаться подтверждения KYC. До подтверждения ставка должна быть недоступна.
[ ] Попробовать ставку ниже шага: получить ошибку без списания.
[ ] Сделать корректную ставку.
[ ] После ставки второго покупателя проверить уведомление о перебитой ставке и сделать ответную ставку.
[ ] Побеждать и покупать через аукцион не требуется.

8. Оформить тест-драйв для подтверждения

[ ] Открыть раздел «Тест-драйв».
[ ] Выбрать любой объект со свободными датами.
[ ] Проверить описание, стоимость, календарь и условия.
[ ] Выбрать даты и оплатить бронь один раз.
[ ] Записать ID брони и передать координатору/продавцу для подтверждения.
[ ] После ответа проверить статус «подтверждено», даты, сумму и уведомления.
[ ] Открыть «Бронирования» и убедиться, что заявка отображается один раз.

9. Переход в продавца — выполнить последним

[ ] Убедиться, что покупка, доля, ставка и бронь уже завершены.
[ ] Вернуться в профиль и нажать «Стать продавцом».
[ ] Прочитать объяснение и шаги, затем продолжить.
[ ] Посмотреть основные разделы кабинета продавца.
[ ] Переключиться обратно в покупателя без выхода.
[ ] Проверить, что профиль, история покупки, портфель, депозит и бронь сохранились.

10. Что отправить координатору

- ID аккаунта, покупки, платежа, доли, депозита, KYC, ставок и брони.
- Скриншоты подтверждения email, карточки объекта, отменённой оплаты и финальной покупки.
- Скриншоты портфеля, ставок, подтверждённой брони и перехода ролей.
- Результат уведомлений: кабинет / email / WhatsApp.
- Ошибки: шаг / ожидание / факт / время / URL / скриншот.

Готово, если целый объект куплен один раз, доля появилась в портфеле, ставки работают после KYC, тест-драйв подтверждён, а переход в продавца выполнен последним без потери данных.
