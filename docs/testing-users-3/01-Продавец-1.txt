ПЕРСОНАЛЬНЫЙ ПЛАН — ПРОДАВЕЦ 1

1. Ваша роль и общий смысл

Вы подготавливаете площадку для двух покупателей. Нужно зарегистрироваться, открыть кабинет продавца, создать пять тестовых сущностей, дождаться их модерации, затем проверить покупки, ставки, долю и заявки тест-драйва.

Не используйте реальные документы, реальные платёжные данные и долговые объекты.

2. Тестовые данные

- URL тестового сайта: ____________________
- Email: ____________________
- Телефон/WhatsApp: ____________________
- Язык интерфейса: ____________________
- Устройство и браузер: ____________________

Тестовая карта: 4242 4242 4242 4242; срок 12/34; CVC 123; Test User; индекс 28001.

3. Обязательная подготовка до персонального сценария

[ ] Открыть URL как гость.
[ ] Выбрать назначенный язык и обновить страницу: язык должен сохраниться.
[ ] Нажать «Профиль» → «Зарегистрироваться».
[ ] Создать новый аккаунт на выданный email.
[ ] Открыть почту и подтвердить email ссылкой или кодом.
[ ] Если письма нет — проверить «Спам» и один раз запросить повторно.
[ ] Вернуться на сайт и убедиться, что аккаунт авторизован.
[ ] «Профиль» → редактирование → заполнить имя, страну и телефон/WhatsApp.
[ ] Сохранить, обновить страницу и проверить, что данные не исчезли.
[ ] Нажать «Стать продавцом».
[ ] Прочитать объяснение и шаги, затем продолжить в кабинет продавца.
[ ] Открыть разделы «Объекты», «Продажи», «Тест-драйв», «Кошелёк», «Аналитика» и «Подписки».
[ ] Активировать назначенный тариф. Первую попытку оплаты отменить, затем оплатить один раз.
[ ] Проверить тариф и уведомления в кабинете, email и WhatsApp.

После этого переходите к созданию объявлений.

4. Создать первый обычный объект

[ ] «Объекты» → «Добавить объект».
[ ] Выбрать формат «Продать сейчас».
[ ] Заполнить адрес через подсказку.
[ ] Заполнить тип, площадь, комнаты, описание, характеристики и цену.
[ ] Загрузить не менее пяти тестовых фотографий и обязательные документы.
[ ] Проверить предварительный просмотр.
[ ] Сохранить черновик, выйти и открыть его снова: данные должны сохраниться.
[ ] Нажать публикацию и отменить первую оплату.
[ ] Убедиться, что списания и опубликованной карточки нет.
[ ] Повторить публикацию и оплатить один раз.
[ ] Записать ID объекта и платежа.
[ ] Дождаться модерации координатором.
[ ] Только после одобрения найти объект в публичном разделе «Купить сейчас».

5. Создать второй обычный объект

[ ] Повторить путь «Объекты» → «Добавить объект» → «Продать сейчас».
[ ] Использовать другие тестовые адрес, цену, описание и фотографии.
[ ] Оплатить публикацию один раз и записать ID.
[ ] Дождаться модерации и проверить карточку в публичном каталоге.

Важно: покупателям передаются только одобренные публичные объекты.

6. Создать объект с долями

[ ] «Объекты» → «Добавить объект» → формат «Доли/Совместные инвестиции».
[ ] Проверить валидацию: пустое, нулевое и недопустимое дробное количество не принимаются.
[ ] Ввести корректное количество долей и цену одной доли.
[ ] Заполнить остальные данные, фотографии и документы.
[ ] Оплатить публикацию, отправить на модерацию и записать начальный остаток.
[ ] После одобрения проверить публичную карточку в разделе «Доли».

7. Создать аукцион

[ ] «Объекты» → «Добавить объект» → формат «Аукцион».
[ ] Заполнить данные, фотографии и документы.
[ ] Указать стартовую цену, минимальный шаг и срок.
[ ] Оплатить публикацию и дождаться модерации.
[ ] В публичной карточке проверить таймер, текущую цену и шаг.

8. Создать объект с тест-драйвом

[ ] Создать отдельный объект и включить тест-драйв.
[ ] Заполнить стоимость, условия и доступные даты.
[ ] Опубликовать объект и дождаться модерации.
[ ] Проверить публичную карточку и календарь.

9. Обработать действия покупателей

[ ] После двух резервов открыть «Продажи».
[ ] Для каждой заявки проверить объект, покупателя, сумму и статус.
[ ] После завершения координатором убедиться, что две продажи отображаются по одному разу.
[ ] После покупки доли проверить количество, сумму и уменьшившийся остаток.
[ ] Проверить последовательность конкурентных ставок в аукционе.
[ ] В «Тест-драйве» одну заявку подтвердить.
[ ] Вторую заявку отклонить с конкретной понятной причиной.
[ ] Проверить уведомления сайта, email и WhatsApp по каждому событию.

10. Что отправить координатору

- ID аккаунта.
- ID всех пяти объектов и платежей публикации.
- Скриншоты публичных карточек после модерации.
- Скриншоты двух продаж, доли, ставок и двух заявок тест-драйва.
- Таблицу сумм: ожидалось / фактически.
- Список отсутствующих уведомлений.
- Ошибки в формате: шаг / ожидание / факт / время / URL / скриншот.

Готово, если все пять сущностей одобрены, две продажи завершены без дублей, остаток долей корректен, ставки видны, а тест-драйв имеет подтверждение и отказ.
