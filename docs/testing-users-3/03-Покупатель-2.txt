ПЕРСОНАЛЬНЫЙ ПЛАН — ПОКУПАТЕЛЬ 2

1. Ваша роль и общий смысл

Вы проверяете второй независимый путь покупателя: регистрация, знакомство с платформой, покупка другого свободного целого объекта, конкурентные ставки и тест-драйв с отказом и понятной причиной.

В продавца не переключайтесь. Долговые объекты не открывайте. Реальные паспортные и платёжные данные не используйте.

3. Обязательная подготовка до персонального сценария

[ ] Открыть URL как гость.
[ ] Выбрать язык и обновить страницу: язык должен сохраниться.
[ ] Нажать «Профиль» → «Зарегистрироваться».
[ ] Создать новый аккаунт на выданный email.
[ ] Подтвердить email ссылкой или кодом из письма.
[ ] Если письма нет — проверить «Спам» и один раз запросить повторно.
[ ] Вернуться на сайт и убедиться, что аккаунт авторизован.
[ ] Заполнить имя, страну и телефон/WhatsApp в профиле.
[ ] Сохранить, обновить страницу и проверить данные.
[ ] С главной открыть «Купить сейчас», «Аукцион» и «Доли».
[ ] В меню открыть профиль, избранное, сравнение, депозит/кошелёк, историю, бронирования и подписки.
[ ] Проверить уведомление о регистрации в кабинете, email и WhatsApp.

4. Выбрать другой объект для покупки

[ ] Открыть «Торги» → «Купить сейчас».
[ ] Выбрать любой доступный объект, отличный от выбора первого покупателя.
[ ] Отправить ссылку координатору и получить подтверждение, что объект свободен.
[ ] Проверить галерею, цену, адрес, описание, характеристики, документы, локацию и продавца.
[ ] Добавить объект в избранное.
[ ] Открыть «Умную панель», рассчитать объект и сверить исходные данные с карточкой.
[ ] Вернуться к выбранному объекту.

5. Купить целый объект

[ ] Нажать «Купить сейчас».
[ ] Открыть PDF, проверить объект, сумму и условия.
[ ] Подтвердить согласие и подпись.
[ ] Начать первую оплату и отменить её.
[ ] Проверить, что объект не куплен и списания нет.
[ ] Повторить путь и оплатить резерв один раз.
[ ] Записать ID заявки, ID платежа и сумму.
[ ] Передать ID координатору и дождаться завершения сделки.
[ ] В «Истории» проверить одну запись с правильным объектом, суммой и статусом.
[ ] Проверить уведомления сайта, email и WhatsApp.

6. Поиграть в аукцион

[ ] Открыть «Торги» → «Аукцион».
[ ] Выбрать тот же активный аукцион, в котором играет первый покупатель.
[ ] Проверить таймер, текущую цену и минимальный шаг.
[ ] Пополнить депозит тестовой картой.
[ ] Подать KYC и передать ID координатору.
[ ] Дождаться подтверждения KYC.
[ ] Перебить ставку первого покупателя корректным шагом.
[ ] Проверить историю ставок и уведомления.
[ ] После ответной ставки проверить уведомление о перебитой ставке.
[ ] Победа и покупка через аукцион не требуются.

7. Оформить тест-драйв для отказа

[ ] Открыть раздел «Тест-драйв».
[ ] Выбрать любой объект со свободными датами.
[ ] Проверить описание, стоимость, календарь и условия.
[ ] Выбрать даты, отличные от брони первого покупателя.
[ ] Оплатить бронь один раз и записать ID.
[ ] Передать ID координатору/продавцу с просьбой отклонить заявку и указать понятную причину.
[ ] Проверить статус «отклонено», даты, сумму и точный текст причины.
[ ] Проверить уведомления сайта, email и WhatsApp.
[ ] В «Бронированиях» должна быть одна отклонённая заявка.

8. Финальная прогулка и проверка данных

[ ] Открыть профиль, избранное, депозит, историю и бронирования.
[ ] Убедиться, что покупка, платежи, ставки и бронь отображаются по одному разу.
[ ] Обновить страницу дважды и повторно проверить отсутствие дублей.
[ ] Не нажимать «Стать продавцом».

9. Что отправить координатору

- ID аккаунта, покупки, платежа, депозита, KYC, ставок и брони.
- Скриншоты подтверждения email, карточки, отменённой оплаты и финальной покупки.
- Скриншоты ставок, отклонённой брони и причины.
- Результат уведомлений: кабинет / email / WhatsApp.
- Ошибки: шаг / ожидание / факт / время / URL / скриншот.

Готово, если другой целый объект куплен один раз, конкурентные ставки работают после KYC, тест-драйв отклонён с видимой причиной, а данные не дублируются.
