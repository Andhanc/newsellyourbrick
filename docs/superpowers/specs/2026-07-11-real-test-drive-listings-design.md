# Реальные объекты на странице тест-драйва

## Цель

Показывать в каталоге `/test-drive` только реальные объекты, которые вернул `GET /api/properties/test-drive`, сохранив текущий визуальный стиль карточек и сетки.

## Источник данных

- Единственный источник объектов — `GET /api/properties/test-drive`.
- Демо-объекты не используются ни при успешной загрузке, ни при пустом ответе, ни при ошибке API.
- API уже ограничивает выдачу объектами с включённым и допустимым тест-драйвом.

## Отображение карточки

Карточка сохраняет текущую разметку и CSS. Из реального объекта берутся:

- идентификатор и ссылка на страницу тест-драйва;
- главное изображение;
- название;
- локация и город;
- тип недвижимости;
- спальни, ванные и площадь;
- цена тест-драйва за ночь и минимальная длительность из `test_drive_data`, с безопасным резервным чтением совместимых полей объекта.

Рейтинг и количество отзывов остаются декоративными значениями, стабильно вычисляемыми по позиции объекта в выдаче. Остальные данные объекта не подменяются.

## Состояния страницы

- Во время запроса сохраняется текущий индикатор загрузки.
- При пустом успешном ответе показывается существующее пустое состояние.
- При ошибке запроса также показывается пустое состояние, без демо-карточек.
- Фильтрация, сортировка, избранное, пагинация и переход в бронирование продолжают работать с реальными объектами.

## Границы изменения

- Серверный endpoint и схема базы данных не меняются.
- Внешний вид карточек и адаптивная сетка не меняются.
- Уже существующие незакоммиченные изменения страницы сохраняются.

## Проверка

- Тест маппинга подтверждает, что реальные поля объекта не заменяются демо-данными.
- Тест источника каталога подтверждает отсутствие демо-заполнения при пустой и непустой выдаче API.
- Выполняются целевые тесты и сборка приложения.
