# Калькулятор доходности — формулы (шпаргалка)

Краткая выжимка формул. Подробное описание — в [INVESTMENT_CALCULATOR.md](./INVESTMENT_CALCULATOR.md).

---

## Вложения и ипотека

| Показатель | Формула |
|------------|--------|
| Общие вложения | `Цена объекта + Стоимость ремонта` |
| Первоначальный взнос (€) | `Цена объекта × (Первоначальный взнос % / 100)` |
| Сумма кредита | `Цена объекта − Первоначальный взнос` |
| Месячная ставка | `Годовая ставка % / 100 / 12` |
| Ежемесячный платёж | `P × (r × (1+r)^n) / ((1+r)^n − 1)` где P=кредит, r=месячная ставка, n=месяцев |
| Годовой платёж по ипотеке | `Ежемесячный платёж × 12` |

---

## По каждому году

| Показатель | Формула |
|------------|--------|
| Стоимость объекта (конец года) | `Стоимость на начало года × (1 + Рост рынка % / 100)` |
| Арендный доход за год | `Доход прошлого года × (1 + Рост аренды % / 100)` |
| Операционные расходы за год | `Арендный доход за год × (Операционные расходы % / 100)` |
| Расходы за год | `Операционные расходы + Годовой платёж по ипотеке` |
| Денежный поток за год | `Арендный доход за год − Расходы за год` |

---

## Итоги за весь период

| Показатель | Формула |
|------------|--------|
| Стоимость через N лет | Значение стоимости объекта на последний год |
| Доход от аренды за период | Сумма арендных доходов по всем годам |
| Чистый денежный поток | Сумма (Доход за год − Расходы за год) по всем годам |

---

## Порядок расчёта в коде

1. Считаем общие вложения, первоначальный взнос, сумму кредита.
2. Считаем ежемесячный и годовой платёж по ипотеке (если ипотека включена).
3. Цикл по годам 1…N:
   - умножаем текущую стоимость на (1 + рост рынка/100);
   - умножаем текущий арендный доход на (1 + рост аренды/100);
   - операционные = доход года × (операционные %/100);
   - расходы года = операционные + годовой платёж по ипотеке;
   - денежный поток = доход года − расходы года;
   - сохраняем в массив по году.
4. Итоги: последняя стоимость, сумма доходов, сумма расходов, чистый поток = сумма доходов − сумма расходов.
