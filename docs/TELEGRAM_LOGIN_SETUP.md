# Как настроить вход через Telegram

## Шаг 1. Создать бота в Telegram

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте команду: **`/newbot`**.
3. Введите имя бота (например: `Sell Your Brick`).
4. Введите **username** бота — он должен заканчиваться на `bot` (например: `SellYourBrickBot`).
5. BotFather пришлёт **токен** вида `123456789:ABCdefGHIjkL-MnopqRStuVwxyz`.  
   **Сохраните его** — он понадобится для сервера.

Username бота (без `@`) тоже запомните — он нужен для фронтенда (например: `SellYourBrickBot`).

---

## Шаг 2. Привязать домен к боту

Telegram разрешает виджет входа только с домена, привязанного к боту.

1. В [@BotFather](https://t.me/BotFather) отправьте: **`/setdomain`**.
2. Выберите вашего бота из списка.
3. Введите домен **без** `https://` и без слеша в конце, например:
   - для продакшена: `yoursite.com`
   - для поддомена: `app.yoursite.com`

**Локальная разработка:**  
На `localhost` виджет часто не работает: Telegram требует домен и HTTPS. Варианты:
- тестировать на выложенном сайте с доменом;
- использовать туннель (ngrok, cloudflared и т.п.) и указать в `/setdomain` домен туннеля.

---

## Шаг 3. Переменные окружения

В корне проекта откройте файл **`.env`** (или создайте **`.env.local`**) и добавьте:

```env
# Токен бота от BotFather (для сервера — проверка подписи)
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjkL-MnopqRStuVwxyz

# Username бота без @ (для фронтенда — показ виджета)
VITE_TELEGRAM_BOT_USERNAME=SellYourBrickBot
```

- **`TELEGRAM_BOT_TOKEN`** — подставьте токен из шага 1.  
- **`VITE_TELEGRAM_BOT_USERNAME`** — подставьте username бота **без** символа `@` (тот же, что в ссылке `t.me/SellYourBrickBot`).

Файл `.env` обычно не коммитится в git — не публикуйте токен.

---

## Шаг 4. Перезапуск

После изменения `.env`:

1. Остановите сервер (Ctrl+C в терминале, где запущен `npm run server`).
2. Запустите снова: **`npm run server`**.
3. Остановите фронтенд (если запущен) и запустите снова: **`npm run dev`** (или вашу команду для Vite).

Vite подхватывает переменные только при старте.

---

## Проверка

1. Откройте сайт и откройте модалку **Вход** / **Регистрация**.
2. Должна быть подпись «Войти через Telegram» и под ней кнопка виджета Telegram.
3. Нажмите на неё — откроется Telegram для подтверждения, затем редирект обратно на сайт и вход в аккаунт.

Если кнопка не появляется — проверьте, что задан `VITE_TELEGRAM_BOT_USERNAME` и перезапущен именно фронтенд (Vite).

---

## Что сохраняется в базе

При входе/регистрации через Telegram в таблице `users` сохраняются:

| Поле                | Описание                    |
|---------------------|-----------------------------|
| `telegram_id`       | ID пользователя в Telegram  |
| `telegram_username` | @username (если есть)       |
| `telegram_photo_url`| Ссылка на аватар (если есть) |

Имя и фамилия из Telegram подставляются в `first_name` и `last_name`. При повторном входе данные обновляются.
