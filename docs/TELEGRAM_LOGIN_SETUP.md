# Вход через Telegram (Login Widget)

## Настройка

1. **Создайте бота** в [@BotFather](https://t.me/BotFather), получите токен.

2. **Настройте домен для виджета**  
   В BotFather: `/setdomain` → выберите бота → укажите домен вашего сайта (например `yoursite.com` без протокола).  
   Для локальной разработки виджет может не открываться (Telegram требует HTTPS и зарегистрированный домен).

3. **Переменные окружения**

   - **Сервер** (обязательно для проверки подписи):
     - `TELEGRAM_BOT_TOKEN` — токен бота от BotFather.

   - **Фронтенд** (чтобы в модалке входа показывалась кнопка Telegram):
     - `VITE_TELEGRAM_BOT_USERNAME` — username бота **без** `@` (например `MySiteBot`).

   Пример в `.env` или `.env.local`:

   ```
   TELEGRAM_BOT_TOKEN=123456:ABC-DEF...
   VITE_TELEGRAM_BOT_USERNAME=MySiteBot
   ```

4. **Перезапуск**  
   После добавления переменных перезапустите и фронтенд (Vite), и сервер.

## Поведение

- В модалке входа/регистрации появляется блок с кнопкой «Log in with Telegram» (виджет Telegram).
- Пользователь нажимает кнопку → переходит в Telegram → после подтверждения возвращается на сайт на `/auth/telegram-callback?...`.
- Бэкенд проверяет подпись (`hash`), при успехе создаёт или находит пользователя по `telegram_id`, отдаёт сессию и редирект в профиль или кабинет владельца.

## Сохраняемые данные

В таблице `users` сохраняются:

- `telegram_id` — идентификатор пользователя в Telegram;
- `telegram_username` — @username (если есть);
- `telegram_photo_url` — ссылка на аватар (если есть).

При повторном входе по Telegram профиль обновляется (username, photo_url).
