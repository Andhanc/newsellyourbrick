# Формат файла Excel/CSV для быстрого добавления объектов

В кабинете продавца можно загрузить один файл **CSV** или **Excel** (.xlsx, .xls) с несколькими объектами недвижимости. В одном файле могут быть объекты **разных типов**: квартиры, дома, виллы, коммерческая недвижимость.

## Структура файла

- **Первая строка** — обязательно заголовки столбцов (на русском или английском).
- **Со второй строки** — данные по одному объекту на строку.

## Обязательные столбцы

| Столбец (рус.) | Столбец (англ.) | Описание |
|----------------|-----------------|----------|
| **тип_объекта** | property_type | Тип: `apartment`, `house`, `villa`, `commercial` (или: квартира, дом, вилла, коммерческая) |
| **название** | title | Название объявления |

## Рекомендуемые столбцы (общие)

| Столбец (рус.) | Столбец (англ.) | Пример |
|----------------|-----------------|--------|
| описание | description | Текстовое описание |
| цена | price | 150000 |
| валюта | currency | USD, EUR |
| страна | country | Испания |
| город | city | Тенерифе |
| адрес | address | ул. Примерная 1 |
| локация | location | Полный адрес одной строкой |
| площадь | area | 85 |
| жилая_площадь | living_area | 70 |
| комнаты | rooms | 3 |
| ванные | bathrooms | 2 |
| этаж | floor | 5 |
| всего_этажей | total_floors | 10 |
| год_постройки | year_built | 2015 |
| тип_здания | building_type | многоквартирный, частный дом, вилла |

## Для квартир / апартаментов

| Столбец (рус.) | Столбец (англ.) | Пример |
|----------------|-----------------|--------|
| квартира | apartment | 42 (номер или название) |

## Для домов и вилл

| Столбец (рус.) | Столбец (англ.) | Пример |
|----------------|-----------------|--------|
| спален | bedrooms | 4 |
| этажей_здания | floors | 2 |
| участок_м2 | land_area | 500 |
| бассейн | pool | 1 или 0 |
| сад | garden | 1 или 0 |
| гараж | garage | 1 или 0 |

## Удобства (0 или 1)

- балкон, парковка, лифт  
- электричество, интернет, охрана, мебель  

В ячейке можно указать: `1`, `да`, `yes`, `true`, `✓`, `+`, `Общий` — будет считаться «включено».

## Фото и видео (ссылки)

| Столбец (рус.) | Столбец (англ.) | Описание |
|----------------|-----------------|----------|
| **фото** | photos | Ссылки на фото через запятую, точку с запятой или пробел. Пример: `https://example.com/1.jpg, https://example.com/2.jpg` |
| **видео** | videos | Ссылки на видео в том же формате. В БД сохраняются как массив объектов с полем url. |

Ссылки должны быть доступны по HTTP/HTTPS. Несколько ссылок в одной ячейке разделяйте запятой, точкой с запятой или переносом строки.

## Дополнительно

- ремонт, состояние, отопление, водоснабжение, канализация — текст  
- для коммерции: тип_коммерции (commercial_type), часы_работы (business_hours)  
- дополнительные_удобства (additional_amenities) — текст  

## Пример строк в CSV

```csv
тип_объекта,название,описание,цена,валюта,страна,город,адрес,площадь,комнаты,ванные,фото,видео
apartment,Квартира в центре,Уютная квартира,150000,USD,Испания,Тенерифе,ул. Примерная 1,85,3,2,https://example.com/photo1.jpg,
house,Дом с садом,Частный дом,320000,EUR,Испания,Коста-дель-Соль,Шоссе 12,180,5,3,,https://example.com/tour.mp4
villa,Вилла у моря,Вилла с бассейном,850000,USD,Испания,Марбелья,Пляжная аллея,250,6,4,https://a.com/1.jpg; https://a.com/2.jpg,https://a.com/video.mp4
```

## Типы объектов

- **apartment** — квартира, апартамент  
- **house** — дом  
- **villa** — вилла  
- **commercial** — коммерческая недвижимость  

В столбце «тип_объекта» можно писать как латиницей (`apartment`, `house`, `villa`, `commercial`), так и по-русски: квартира, дом, вилла, коммерческая. Также поддерживаются **Жилая** (тип уточняется по названию: если в названии есть «Дом» — house, «Вилла» — villa, иначе apartment) и **Коммерческая** (commercial).

## После загрузки

После выгрузки откроется модальное окно:

- **В файле найдено N объектов** — количество строк с объектами в файле.  
- **Загружено M%** — доля успешно добавленных объектов (и число «X из N»).  
- Если есть ошибки по строкам — будет показано сообщение «С ошибками: K» и кратко первые ошибки (номер строки и причина).

Скачать готовый шаблон с примером строк можно в модальном окне по кнопке **«Скачать шаблон Excel/CSV»**. В папке `docs` лежит пример файла **`sample_bulk_import.csv`** с полным набором столбцов и примерами ссылок на фото и видео.
