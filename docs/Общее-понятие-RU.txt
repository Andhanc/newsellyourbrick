SellYourBrick — общее понятие

SellYourBrick — онлайн-платформа для покупки и продажи недвижимости. Есть два кабинета: покупатель и продавец. Можно переключаться между ролями.
1. Типы продаж

- Аукцион — ставки, таймер, конкуренция. Победа возможна только после окончания аукциона.
- Купить сейчас — фиксированная цена, быстрая сделка без ожидания конца торгов.
- Долги — объекты с долгом / дисконтом; тоже можно купить через «Купить сейчас» или аукцион.
- Доли — покупка части объекта (со-инвестиции), низкий порог входа.
- Тест-драйв — короткое проживание в объекте до решения о покупке.
- VIP / Private Club — закрытые лоты, документы, персональный менеджер.
2. Что делает покупатель

- Ищет объекты, сравнивает, считает в умной панели.
- Пополняет депозит, проходит проверку (KYC).
- Делает ставки, покупает «сейчас», покупает доли, бронирует тест-драйв.
- Оформляет подписку Starter / Pro / VIP.
- Связывается с умным помощником и (с VIP) с персональным менеджером.
3. Что делает продавец

- Публикует объекты в нужном формате продажи.
- Выбирает тариф Basic / Standard / Pro / VIP-Institutional.
- Смотрит аналитику, заявки тест-драйва, продажи.
- Получает интерес покупателей и статусы сделок.
4. Умный помощник

На все вопросы по платформе отвечает умный помощник (AI-чат):
- как купить / продать;
- чем отличаются аукцион, «Купить сейчас», долги и доли;
- как подобрать объект под бюджет и город;
- куда нажать дальше.
Откройте меню → Сервисы → AI-помощник / Чат и напишите свой вопрос своими словами.
5. Как платить (тестовый стенд)

Для всех тестовых оплат используйте Stripe Test card:
1. Карта: 4242 4242 4242 4242
2. Срок: любой будущий, например 12/34
3. CVC: любые 3 цифры, например 123
4. Имя / страна / индекс: любые, например Test User / Spain / 28001
Этой картой платят: подписки, публикацию объекта (~29 EUR), депозит, резерв 10% «Купить сейчас», доли, тест-драйв.
После Buy Now / победы в аукционе менеджер может прислать реквизиты дальнейшего платежа. На тестовом стенде пример реквизитов:
- Счёт: BY36ALFA30122345678901234567
- Назначение: первоначальный платёж по сделке (указывается в письме)
На проде реквизиты берутся из настроек платформы. В тесте достаточно карты 4242 и проверки статусов на сайте.
6. Уведомления

После важных действий проверяйте: кабинет на сайте, email, WhatsApp (если номер привязан).
7. Важная пометка для текущего теста

Сейчас аукционы ещё не закончились по таймеру, поэтому покупатель не может выиграть лот через аукцион. В аукционе можно только поиграть: сделать ставки, проверить депозит, KYC, уведомления. Реальную покупку в этом тесте делайте только через «Купить сейчас» (обычный объект, долг) или через покупку доли.
