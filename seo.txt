SEO-аудит и база измерений

Подключить/проверить Google Search Console.

Снять baseline: индексируемые URL, позиции, клики, CTR, Core Web Vitals, ошибки покрытия.

Критичная техническая индексация

Сделать robots.txt: разрешить публичные страницы, закрыть /admin, /profile, /wallet, /chat, служебные API, приватные документы.

Сделать динамический sitemap.xml: главная, категории, карточки объектов, новости, информативные страницы.

Добавить отдельный image sitemap для объектов недвижимости

для несуществующих\неверных ссылок страниц , закрытых объектов реализовать страницу 404

Рендер страниц 

<title>, <meta name="description">, canonical, OG и JSON-LD прямо в HTML-ответ.

Для карточек объектов HTML должен содержать уникальный title, description, h1, фото, цену, город, тип объекта.

Мета-теги и шаблоны

Главная: title про бренд + основной оффер.

Аукцион: “Аукцион недвижимости в Испании”.

Карточка объекта: {тип} в {городе}, {площадь} м², {цена} | Sellyourbrick.

Новости: title статьи + бренд.

Категории: “Купить квартиру в Испании”, “Дома у моря”, “Недвижимость с долгами”, “Долевая недвижимость”.

Для каждой страницы: unique title, meta description

Архитектура URL

Сделать человекочитаемые URL вместо только ID, например /property/villa-costa-brava-123.


Для городов: /spain/barcelona/apartments, /spain/tenerife/villas.

Для разделов: /auction, /shares, /debts, /test-drive.


Старые URL с ID оставить через 301 на новые.


Внутри сайта использовать обычные <a href="">, чтобы Google видел связи между страницами.

Внутренняя перелинковка

Главная должна ссылаться на ключевые разделы.

Карточки объектов должны ссылаться на город, страну, похожие объекты, тип недвижимости.

Новости должны ссылаться на коммерческие страницы.

Добавить блоки “Похожие объекты”, “Недвижимость в этом городе”, “Гайды по покупке”.

Проверить, чтобы важные страницы были доступны за 2-3 клика от главной.
