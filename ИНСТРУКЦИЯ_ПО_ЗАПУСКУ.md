# 🚀 Инструкция по запуску проекта

## 📋 Требования

- Node.js 20+
- PostgreSQL 14+ (локально или удаленно)

Проверка:

```bash
node --version
npm --version
```

## 🔧 Быстрый старт

1) Установите зависимости:

```bash
npm install
```

2) Создайте `.env` на основе `.env.example` и заполните минимум:

```env
DATABASE_URL=postgresql://USER:PASSWORD@HOST:5432/DB_NAME?schema=public
```

3) Примените миграции Prisma:

```bash
npm run db:deploy
```

4) Запустите проект:

- фронтенд: `npm run dev` (порт 5173)
- бэкенд: `npm run server` (порт 3000)

или сервер с авто-перезапуском:

```bash
npm run server:dev
```

## 🗄️ База данных

Проект работает только с PostgreSQL через Prisma.

- SQL-миграции хранятся в `prisma/migrations`
- генерация Prisma Client: `npm run db:generate`
- статус миграций: `npm run db:status`

## 🎯 Проверка работы

После запуска:

1. Откройте `http://localhost:5173`
2. Убедитесь, что сервер отвечает на `http://localhost:3000`
3. В консоли сервера должно быть сообщение об успешной инициализации PostgreSQL

## 🔍 Устранение проблем

### Порт занят

Освободите порт 3000/5173 или поменяйте конфигурацию.

### Ошибка подключения к БД

- проверьте `DATABASE_URL`
- убедитесь, что PostgreSQL запущен и доступен
- выполните `npm run db:deploy`

### Prisma ошибка про адаптер/движок

Переустановите зависимости:

```bash
npm install
```

и проверьте, что в проекте есть `@prisma/adapter-pg`.
